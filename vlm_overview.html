VLM 对抗补丁 · 研究状态总览

Stop-Patch:白盒 → 跨架构迁移 → 决策墙(有条件) → 物理可用

一块纯对抗噪声补丁,让视觉语言模型幻觉出 STOP 标志并决定停车。研究白盒是否起效、能否泛化、能否迁到真正跨架构的 VLM、决策层能否被攻破、打印后是否仍生效。

白盒源 = Qwen2.5-VL-3B迁移金标 = InternVL2-2B更新 2026-07-20
  • 白盒 Qwen2.5-VL-3B **~100%**;可微管线逐位复刻,梯度精确回补丁像素。
  • 跨架构迁移干净头条:**InternVL2 合取 .675 [.52,.80]**(感知顶到 1.0,动作封 ~.68)。
  • **当前瓶颈 = 决策墙,且是有条件的**:感知易迁移、决策鲁棒(六种突破全败);action 只在**"场景可驾驶 ∧ 看见 STOP"**时才升级到硬停。
  • 物理(受控配对):**感知大幅领先**(n=30 sign .90 vs 学长 .60),**停车打平**(.233),clean action=0 证因果。
  • **两个已确定的机制成分**:①**表观尺寸**(峰≈1/3,非单调);②**驾驶场景**(不对称检验:感知持平、indoor 尺寸占优,换非驾驶场景仍把停车 .667→.200)。

§0术语 & 指标

sign
感知 ASR:模型答"有 STOP 标志"。最干净。
action
停车决策 ASR。单独看会被场景混淆。
conj
逐图 sign ∧ action 再平均。因果指标。
strict / liberal
action 只认字面 "stop" vs 也把 "do not drive" 算停(抬高 clean、慎用)。
地板
clean(无 patch)/ random(5-seed 随机噪声)。
Wilson / McNemar
比例 95%CI / 配对二元精确检验。
核心红线:名义 vs 因果停车可能是把 patch 当 STOP 标志(真起效),也可能是场景吓的。测试集剔除真 STOP 标志 + 逐图合取,把"停"钉在"看见标志"这条因果链上。放宽这条 = 全错。

① 表观尺寸 = 杠杆,但非单调(峰≈1/3)同场景内 z100→z70 把 action .267→.600(clean ~0 → 纯 patch 驱动,McNemar p≈.01);但 z55 更大反降 .400 → 甜点 ≈ 1/3,别撑满。probe3:固定 z70 遮掉上半的路,action 仍 .600 → 远处的路无关(早前"上下文重要"多是尺寸的确认偏差)。
② 驾驶场景 = 控制 action 的关键、独立因素(不对称检验 scene_iso)把 outdoor/indoor 的 mine 图裁到可比:两组 sign 都 .933(感知持平)、且 indoor 的 patch 反而更大(占尽尺寸便宜)——但 indoor action .200 vs outdoor .667(差 3×)。感知持平 + indoor 尺寸占优,换成非驾驶场景仍把停车打到 1/3 → 场景效应压过尺寸优势 = 保守而有力的证据。

措辞层级(挡"你怎么知道不是光照"追问):主张的是"场景类型作为整体"(户外包 vs 室内包)控制 action——光照/背景是室内外根本且不可分的差别,真车永远处在完整户外包里,所以这正是部署相关的正确比较单位,不需/无法把"路语义"从光照里单剥。结合 probe3(远处路可遮)→ 机制 = "整个场景像不像可驾驶户外语境"。
诚实边界全是数字裁剪探针,不上报(裁剪不增细节;且模型无论输入多大都降到 448,只有 patch 占框比例进得去)。z55 的 patch 其实大多完整,回落机制未定。作为受控下界估计:真实按 ~1/3 重拍预示 action .5–.6;不破决策墙(上限仍 ~.68)。
交叉验证(现有数据能验的都验完 · 全过)① 分类器:~44 条原始回答人工核 vs 分类器 = 100% 一致(地基稳)。② clean 双场景对照:clean_outdoor / clean_indoor 同裁法 action 都 ~0(.067) → 户外场景本身不停车、是门控 patch 效应,加固"驾驶场景是独立因素"。③ 尺寸曲线:sz100/85/70/60 = .267/.333/.600/.333 → 倒 U、峰≈1/3 坐实。剩余洞(跨架构 n=1、物理功效、决策墙跨 VLM 普适)= 要新资源的 limitation。

§6结论 & 卖点

  • 干净跨架构迁移可行(InternVL2 合取 .675,两轴外部)。
  • 瓶颈 = 决策墙,且是有条件的(核心贡献):感知易迁移、决策鲁棒(六种突破全败);action 只在 "场景可驾驶 ∧ 看见 STOP" 时升级到硬停。感知/patch质量/迁移/表观尺寸都已确定不是瓶颈。
  • 决策墙不是黑箱天花板,而是可分解的:两个已确定的机制成分 —— 表观尺寸(峰≈1/3)、驾驶场景(整体户外语境)。这让"决策墙"从负结果升级成有机制的正向刻画。
  • 物理可用:受控配对下感知大幅领先、停车打平且 clean=0 证因果。

§7下一步

  • 重拍 outdoor(可选 · 边际收益小):patch 占框 ~1/3(非 1/5、别撑到 1/2)、完整居中;只把探针的 .6 转成"可上报的物理数"——数字本身不会更高(patch 粗、模型降 448,拍近不加有效细节)。
  • 驾驶场景物理对照(彻底钉死,可选):同 patch 同 ~1/3 尺寸,路边 vs 纯墙,同机位。但不对称检验(indoor 占尽尺寸+感知便宜仍输 3×)已很有说服力。
  • 补 n / wall 场景 → 锁配对显著性。

§8诚实边界

  • 固定居中 · 单模型 Qwen2.5-VL-3B 白盒 · 贪心解码 · 真攻击率是保守下限 · 跨 prompt 部分依赖措辞。
  • 决策墙对图像攻击鲁棒(.675 带机制天花板,六种突破全败)—— 结论不是缺陷。
  • 物理 n 小(每场景 15)、CI 宽;§4e 全是数字裁剪探针,须标注不当上报物理数。
  • 驾驶场景的证据是不对称检验(保守);主张在"场景类型整体"层级,未把语义从光照/背景单剥(部署里本不可分)。
