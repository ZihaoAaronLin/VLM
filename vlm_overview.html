VLM 对抗补丁 · 研究状态总览

Stop-Patch:白盒 → 跨架构迁移 → 决策墙 → 物理可用

一块纯对抗噪声补丁,让视觉语言模型幻觉出 STOP 标志并决定停车。研究其(a)白盒是否起效、(b)能否泛化、(c)能否迁到真正跨架构的 VLM、(d)决策层能否被攻破、(e)打印后是否仍生效。

白盒源 = Qwen2.5-VL-3B-Instruct迁移金标 = InternVL2-2B更新于 2026-07-19
  • 白盒 Qwen2.5-VL-3B **~100%**;可微管线逐位复刻,梯度精确回补丁像素。
  • 跨架构迁移干净头条:**InternVL2 合取 .675 [.52,.80]**(感知顶到 1.0,动作封顶 ~.68)。
  • **决策墙**:感知极易跨族迁移,决策鲁棒——**六种突破全部失败**,是带机制的稳健上限,不是没调好的数。
  • 物理(受控配对):**感知大幅领先**(sign .90 vs 学长 .60),**停车打平**(.233);无 patch 对照停车率 = 0,证明因果。
  • **新发现(探针+对照验证)**:patch 占框 ~1/3 且保留驾驶场景 → 停车 **.267 → .60**(clean 仍 ~0,纯 patch 驱动)。表观尺寸是可回收的物理杠杆。

§0术语 & 指标(全项目统一)

sign
感知 ASR:模型答"有 STOP 标志"。最干净、最可信的指标。
action
停车决策 ASR:模型决定停车。单独看会被场景混淆。
risk
风险 ASR:判场景危险。
conj
逐图 sign ∧ action 再对图平均。因果指标:同一张图既看见标志又决定停。
strict / liberal
action 只认字面 "stop"(严格) vs 也把 "do not drive / avoid driving" 算停(宽松,会抬高 clean、慎用)。
地板
clean(无 patch) / random(5-seed 随机噪声)。效果需超过地板才算真。
Wilson CI
比例的 95% 置信区间,小样本/极端比例比正态近似准。
McNemar
配对二元数据的精确检验(同机位 clean vs patched)。p 越小越不像巧合;p<.05 显著。
项目核心红线:名义 vs 因果模型"停车"可能是把 patch 当 STOP 标志(真起效),也可能是觉得场景危险而保守停(场景吓的)。测试集人工剔除了所有真 STOP 标志 + 用逐图合取,把"停"钉在"看见标志"这条因果链上。放宽这条 = 全错。

4e · 新发现:表观尺寸 × 场景(裁剪探针 + clean 对照)

把 outdoor 的 mine 图往 patch 上裁紧(放大 patch 占比、保留驾驶场景),同样裁剪也用到 clean 上作对照。

放大档clean actionmine actionmine conj净效应(clean→mine)
z100(原始 · patch ~1/5).000.267.267+.267
z55(太紧 · 丢较多场景).000.400.400+.400
z70(甜点 · patch ~1/3 · 留住路).067.600.533+.533
对照通过 → 效果是 patch 引起的clean 在所有放大档都 ~0(.000/.000/.067),mine 却 .267→.400→.600。裁紧本身不会让空场景停车 → "放大 patch 把停车顶到 .6"纯由 patch 驱动(净效应 +.533,粗算 McNemar p≈.01)。

机制:action 需要两个条件同时满足 —— patch 够大(被看见)∧ 场景像驾驶场景(有路)。甜点约 1/3;太紧(z55)丢场景反而回落。这解释了 indoor 为何失败(有大 patch 但没路)。
诚实边界这是数字裁剪探针,不能当上报的物理数(裁剪不增加真实细节)。但它是受控的下界估计——真的拍近,细节比放大裁剪更多,只会更好。它强烈预示真实重拍能到 .5–.6。这不是打破决策墙(数字上限仍 ~.68),而是把物理 action 从 .267 找回到接近上限。

§6方法学要点(答辩守得住)

  • 名义 vs 因果:测试集剔除真 STOP 标志 + 逐图合取,把"停"钉在"看见标志"上。
  • 严格口径 + 有效零基线:只有严格 action 下 clean=0,才能把停车归因给 patch;宽松会抬高 clean、反帮对照。
  • 配对 + McNemar:同机位 clean/mine/senior,场景当常量,翻转干净归因;场景本就吓停的样本(concordant)自动被剔除。
  • 表观尺寸 × 场景:action 是两者的交互,不是单因素;报物理必须同时控制"patch 占框比例"与"驾驶场景是否在框内"。

§7结论 & 卖点

  • 干净跨架构迁移可行(InternVL2 合取 .675,两轴外部)——集成/表征对齐是关键。
  • 决策墙是核心负结果:感知易迁移、决策鲁棒,六种突破全败——带机制的稳健上限,是卖点不是缺陷。
  • 物理可用:受控配对下感知大幅领先、停车打平且 clean=0 证因果;表观尺寸×场景可把停车从 .267 找回到接近上限。
